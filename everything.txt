# DLASS Project Context

## Architecture
- **Frontend**: React + Vite + Tailwind CSS.
- **Backend**: Spring Boot + Java (running on port 8080).
- **Database**: MongoDB.
- **Authentication**: JWT based.

## Key Modules
- **Login / Register**: Works under `/api/auth/...`.
- **Provider Dashboard**: React `ProviderDashboard.jsx`. Backend `ServiceProviderController` + `ServiceProviderService`.
- **User Dashboard**: React `UserDashboard.jsx`. Backend `UserController` + `UserService`.
- **Search & Provider Detail**: React `SearchProviders.jsx` -> `ProviderDetail.jsx`. Backend `/api/providers/{providerId}/profile` returning `ProviderProfileResponse`.
- **Chat System**: UI exists in `ChatWindow.jsx`. Syncs correctly via websockets / SSE / polling.
- **Static Assets / Avatars**: Managed via `StaticResourceConfig.java` in backend. Avatars upload to `/api/providers/upload-avatar` and `/api/users/upload-avatar` (persisted to `uploads/avatars`). Provider portfolios are uploaded to `uploads/provider`. Accessed cleanly via `http://localhost:8080/uploads/avatars/...` and `http://localhost:8080/uploads/provider/...`.
